---
name: Hyphen-free website copy
description: How to reconcile the user's request for fewer visible hyphens with correct spelling and stable technical values.
---

Use natural grammatical alternatives when removing hyphens from website copy. Do not simply turn a compound modifier into two unhyphenated words.

**Why:** A literal removal pass produced awkward or incorrect phrases such as “six digit code” and “post call experience,” despite the user's simultaneous request to correct spelling.

**How to apply:** Review visible copy in context and rephrase the whole sentence where necessary. Preserve the meaning of time and size ranges. Leave URLs, HTML autocomplete tokens, code identifiers, and proper names untouched when their hyphens are required.
