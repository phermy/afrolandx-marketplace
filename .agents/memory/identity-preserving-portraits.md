---
name: Identity-preserving portraits
description: How to handle edits to real-person portraits when likeness must remain faithful.
---

For a real person's portrait, especially after a user asks to use their actual attached photograph, preserve the original person's pixels and pose. Treat generative output as a source for a replacement background rather than as a replacement for the person. Make wardrobe-color changes only on the subject's garment region and inspect the final face and edges.

**Why:** A generative edit based on the original photo changed the person's facial appearance even when explicitly instructed to preserve it. The user clarified that they wanted their real attached picture, not a reinterpretation.

**How to apply:** When changing a real person's clothing or surroundings, prefer a cutout of the original photograph composited against the new background, with selective garment retouching. Verify both the full-resolution result and its actual website crop before presenting it.
