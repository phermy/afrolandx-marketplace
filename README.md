# AfrolandX Marketplace

## About AfrolandX

AfrolandX is an Africa-focused digital marketplace designed to connect customers with local products and businesses across African countries.

The platform aims to make it easier for customers to discover, purchase, and support products and businesses from across Africa.

## Key Features

* African-focused online marketplace
* Product discovery and search
* Customer accounts and authentication
* Shopping cart and checkout
* Vendor and product management
* Order management
* Image and product uploads
* Location-based services
* Deals and promotions
* Premium services
* Payment integration
* Administrative management tools

## Technology

The project uses a modern full-stack web architecture, including:

* TypeScript
* React
* Node.js
* Vite
* Express
* Drizzle ORM
* PostgreSQL
* Tailwind CSS

## Development

Clone the repository:

```bash
git clone https://github.com/phermy/afrolandx-marketplace.git
cd afrolandx-marketplace
```

Install dependencies:

```bash
npm install
```

Configure the required environment variables before starting the application.

Run the development environment using the project's configured npm scripts.

## Deployment

The project is maintained in GitHub and can be deployed to supported hosting providers.

The production website is currently maintained separately from the GitHub repository. Additional hosting environments can be connected to the repository for backup, testing, and future production deployment.
